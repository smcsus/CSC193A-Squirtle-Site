# CSC193A Squirtle Site

This is a static website built for the CSC193A course in Spring 2025. It showcases Squirtle using basic HTML and CSS, with separate pages for content like fan art and character information.

## Features

- Home page with images and overview
- About page with Squirtle's history
- Gallery page with fan art
- Contact page for user feedback
- Responsive design for desktop and mobile

## Technologies

- HTML5
- CSS3
- Hosted with GitHub Pages
